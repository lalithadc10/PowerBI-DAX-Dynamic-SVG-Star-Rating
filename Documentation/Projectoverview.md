

#  LinkedIn Project Walkthrough

I created a short LinkedIn walkthrough to share the thinking behind this mini-project and demonstrate how I used **DAX + SVG in Power BI** to create a dynamic star-rating visual.

###  What the walkthrough covers

- The business question behind the analysis
- Why I chose a simple approach instead of adding unnecessary visuals
- How the product rating is converted into a visual star rating
- How DAX controls the filled and empty stars
- How SVG is generated dynamically inside Power BI
- How the visual can make customer ratings easier to understand
- How the rating can be compared with product performance metrics
- What I learned from building the visual

###  Key Message

> **I didn't start with "What visual can I create?"  
> I started with "What business question am I trying to answer?"**

The SVG star rating was then used as a simple visual communication technique to make the customer-rating information more intuitive.

**Business Question → DAX Logic → SVG Visual → Better Communication → Business Investigation**
